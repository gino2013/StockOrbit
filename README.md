# StockOrbit

自動追蹤 Firstrade 持股，產生投資建議報告(含再平衡策略回測)，並提供網站隨時查看持股狀況。

## 功能規劃

- **持股同步**：自動登入 Firstrade 抓取目前帳戶持倉與交易紀錄
- **建議報告**：根據目前持股狀況給出配置分析與調整建議
- **回測**：對自訂的再平衡策略進行歷史回測
- **網站儀表板**：隨時查看持股現況、報告與回測結果

## 狀態

專案剛啟動，架構與技術細節規劃中。

## 技術棧

- 後端／網站：Python
- 持股資料來源：Firstrade（透過非官方 API 自動登入抓取）

## 安全性注意事項

Firstrade 帳號密碼與 2FA 金鑰僅會以環境變數／部署平台的 Secret 管理方式儲存，不會提交進版本控制。
